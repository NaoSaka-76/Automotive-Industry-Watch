# Automotive Industry Watch

トヨタ自動車の最新トピックス、世界の自動車産業ニュース、モータースポーツの話題を
30分ごとに自動収集し、GitHub Pagesで公開するモニタリングダッシュボード。

## 構成

- **① トヨタ自動車 最新トピックス** — 株価チャート(7203.T、直近3ヶ月)と最新決算ダイジェスト(売上高・営業利益・
  経常利益・最終利益・前年同期比)を上部に表示。ニュースはトヨタ自動車に関するものを日英で収集し、
  自動車産業トピックスと同様に新製品・新技術・規制・経営・政策・他へ自動分類(参考値)。最新順/話題順を切替可能。
- **② 自動車産業に関するトピックス** — グローバル・日本・アメリカ・ヨーロッパ・アジア・オセアニア・
  アフリカ・中東・ロシアの8地域+グローバルで収集。各記事は見出しのキーワードから
  新製品・新技術・規制・経営・政策・他へ自動分類(参考値)。地域タブ→カテゴリタブ→最新順/話題順の
  3段階で絞り込み可能。
- **③ モータースポーツ** — F1・WEC/ル・マン(耐久)・WRC/ラリー・NASCAR/IndyCar(北米)・
  Super GT/スーパーフォーミュラ(国内)・Formula E(電動)・クロスカントリーラリー(ダカール等)・
  ドリフト(D1GP等)・全日本ラリー選手権(国内)の9カテゴリーを集約。

ページ上部の「直近24時間ダイジェスト」で、①トヨタ自動車トピックス/②自動車産業に関するトピックス/
③モータースポーツの3大分類ごとに24時間以内の更新件数を一覧できる。24時間以内に公開された記事は
一覧上でも赤枠+バッジでハイライトされる。各カテゴリーの記事一覧はスクロールウィンドウ形式にしており、
ページ全体が際限なく長くならないようにしている。

## 既知の制約

- **APIキー不使用**: YouTube Data API・X API等の有料/要承認APIは使わず、Google News RSS
  (無料・無認証の公開フィード)のみでデータを収集している。
- **記事本文は取得不可**: Google News RSSのリンクはリダイレクト経由でJS描画される
  `news.google.com` の中間ページを経由するため、`requests` では実際の記事本文を取得できない。
  そのため見出し(タイトル)のみを対象としている。
- **「話題順」は関連度順の代替指標**: 記事本文もエンゲージメント数(閲覧数・シェア数等)も
  取得できないため、「話題順」はGoogle News検索結果内での表示順(関連度順)を代替指標として
  用いている。実際の話題性・拡散度を示す指標ではない。
- **自動分類は参考値**: 自動車産業トピックスのカテゴリー分類(新製品/新技術/規制/経営/政策/他)は、
  見出しテキストのキーワードマッチによる自動推定であり、厳密な分類ではない。
- **地域別クエリの言語**: 日本のみ日本語クエリを使用。それ以外の地域(アメリカ・ヨーロッパ・
  アジア・オセアニア・アフリカ・中東・ロシア)は、すべて英語で報じられた国際ニュースのみを
  対象としている(現地語での報道は対象外)。
- **真のリアルタイム更新ではない**: GitHub Pagesは静的ホスティングのためサーバー側処理ができず、
  GitHub Actionsのcronによる30分毎のバッチ更新となっている。
- **株価データ**: Yahoo Financeの非公式・無認証のチャートAPI(`v8/finance/chart`)から取得している。
  APIキー不要だが非公式エンドポイントのため、構造変化やレート制限で取得できなくなる場合がある。
- **決算データ**: 株探(kabutan.jp)の業績推移ページ(静的HTML)から直近四半期(3ヶ月)決算を取得している。
  非公式の第三者集計サイトであり、正式な数値はトヨタ自動車の決算短信(IR資料)を参照のこと。

## ローカルでの実行

```bash
cd scripts
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python fetch_data.py
```

`site/data/latest.json` が生成される。`site/` ディレクトリを任意の静的サーバーで配信すれば
ローカルで表示を確認できる(例: `python3 -m http.server --directory ../site 8000`)。

## デプロイ

GitHub Actions (`.github/workflows/update-dashboard.yml`) が30分毎に `scripts/fetch_data.py` を
実行し、`site/` を GitHub Pages にデプロイする。
